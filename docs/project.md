# monopoly

像素风中国城市大富翁，目标是丰富传统掷骰、购地、收租玩法，后续适配微信并上架。
当前阶段为可玩的本地浏览器原型，先验证玩法与视觉。代码仓库：[The0xKa1/monopoly](https://github.com/The0xKa1/monopoly)，主分支 main。

## 当前内容

- 经典地图 12 城：北京、西安、成都、重庆、武汉、南京、杭州、上海、广州、深圳、厦门、青岛。
- 统一城市库 88 城：中国 58 城（34 个省级行政区对应城市 + 24 个旅游城市）、世界 30 城。
- 图鉴支持中国 / 世界 / 当前棋盘、地区筛选、城市和地标搜索及像素画预览。
- 支持经典地图，以及中国 / 世界 / 混合随机地图；可选 20 / 28 / 36 格，对应 12 / 20 / 28 座城市。
- 地图设置先预览城市，可重新随机；应用后重开并保留角色，取消不修改当前对局。
- 可变大小的环形棋盘；默认 1 位玩家与 3 位 AI，可新增至总计 20 个角色；每人初始现金 ¥12,000。
- 轮数可在“地图设置”中设为 1～999 或无限（默认 20，旧存档为 20）；只改轮数可直接保存到当前对局，不低于当前轮。无限轮时只在仅剩一人时结束，也可在“重新开始”中立即结算（仅本人回合、无待处理事项时）。
- 到达轮数后按总资产结算：现金 + 城市/产业净值 − 待付款；抵押资产净值扣除抵押款，仅剩一人未破产时提前结束。
- 购城、收租、升级至 4 级；付租前可提出收购，报价为地产原价 + 累计实际升级支出。
- 业主同意后转让产权并免本次租金，拒绝则继续付租；本人持有的城市由本人确认，其他业主由 AI 决定。
- 现金不足时选择房产抵押，金额为地产原价的 50% + 累计实际升级支出；筹足后确认付款。
- 银行代持期间不收租、不可购买或升级；在自己的掷骰前或回合结束时，从资产详情按原额赎回。
- 已无可抵押房产且现金仍不足时确认破产；只支付剩余现金，未付余额不再追偿，全部房产公告回流市场、等级归零。
- 集齐当前地图同色组全部城市，租金 ×1.5；旅行季每 4 轮更替，对应区域租金 ×1.3，可叠加。
- 道具：遥控骰子、租金护盾、建设补贴，在掷骰前使用。
- 特殊格为起点、奇遇、城市事件及五类公共事业；取消道具驿站、免费高铁/度假/庆典奖励，道具仍通过事件获得。
- 全部地图保留城市索引和数量；经典索引 6 / 10 / 13 / 16 / 18 分别为铁路 / 航运 / 航空 / 太空 / 水电，随机地图按比例定位。
- 铁路 ¥1,800：同业主在营交通产业（铁路/航空/航运）1 / 2 / 3 种时收费 ¥200 / ¥400 / ¥800。
- 航空 ¥2,400：本次骰点 × ¥100；同业主铁路在营时 ×1.5。航运 ¥2,000：¥200 + ¥80 × 来客未抵押城市数（最多 10 城）；同业主水电在营时 ×1.5。
- 太空冒险 ¥3,000：¥300 + ¥50 ×（轮数 − 1）；同业主航空在营时 ×1.5。水利电力 ¥2,200：骰点 ×（¥80 + ¥20 × 同业主其他在营产业数）。
- 产业可购买与收购，不升级；服务费不受城市季节/同色组/角色租金加成或护盾影响，也不消耗护盾，到站锁定报价。
- 产业按原价收购，同意后免本次服务费；抵押款为原价 50%，银行代持不收费/禁售/停联动，原额赎回恢复联动，破产公告回流。
- 点击产业格查看业主、公式、联动状态，可切换骰点/来客预览；预览不改变对局，钱包同时列出城市与产业。
- 城市数量、免费改建、城市抵押减免等事件只作用于城市；产业产权随存档恢复，城市重排不移动产业及其产权。
- 棋盘顶部“事件卡测试”按奇遇 / 城市事件分池；30 张奇遇与当前地图城市卡均可进入独立样本、重试和返回原对局。
- 测试保留当前地图/角色，准备现金/产权/抵押样本，支出卡支持现金不足；可看实际变化并继续试用道具。
- 测试单独存档，刷新可继续，退出还原原对局；测试不轮转 AI，涉及业主收购确认仍正常答复。
- 88 张城市专属事件，每城一张，只有本局出现的城市入池；经典地图 12 张，随机地图按城市数启用 12 / 20 / 28 张。
- 城市事件有独立地图格、原创像素站点及本局卡池预览；替换原第 9 格奇遇，城市索引和地图大小保持，旧待抽奇遇可继续。
- 城市卡以城市库地标为卡面，含地域故事、本城旅行/改建/抵押减免、活动补贴与业主奖励，以及收支/道具/地图效果。
- 城市活动补贴由银行支付，只有本城未抵押且未破产的业主领取额外奖励；业主是抽卡者时兼得。
- 30 张通用奇遇事件卡，金色像素卡背展开三选一，翻面揭示故事、图标和准确效果，再确认执行。
- 资金事件覆盖银行奖励/支出、全员礼金、生日红包、最富向最穷转账、现金利息、按地产数量结算检修费/集市收益。
- 房产事件可选自有未抵押房免费升 1 级（实际升级支出不增加），或由银行免除一笔抵押、归还产权；无符合条件房产改领 ¥500。
- 自选奖励可挑一种道具或在现金与骰子间选择；全城午睡使所有活跃玩家获得一次免租，已有护盾不叠加。
- 多人付款现金不足时接入抵押；破产仅按比例分配实际剩余现金，整数余款按玩家顺序补齐，不凭空发钱。
- 地图事件支持随机重排、完全反转、顺次轮转，城市聚拢后回位；特殊站点固定，产权/抵押及站在城市的人物随城市迁移。
- 移动事件覆盖任选城市、未售城市、自有城市和顺时针第 3 城；巴士逐格前进，其余播放传送动画；不领起点奖励，到站按普通购地、升级、收租或护盾规则结算。
- 道具事件赠遥控骰子、租金护盾或建设补贴，进入背包后按原规则使用；建设补贴最多抵扣 ¥600。
- 每次揭示写入全体可见的抽卡公告；抽卡、揭示、选目的地和事件选项均随存档恢复，刷新不重抽、不重复执行。
- 选择目的地与奖励共用 `eventOptions.js` 的实时合法目标，UI 与结算校验一致；无目标时按卡面兜底结算。
- AI 自动抽取、短暂停留展示卡面后执行；新事件金额对所有角色一致，不叠加旧奇遇额外奖励。
- 所有玩家均可自定义肤色、发型、发色、服装、帽子、眼镜和配饰，支持随机外观与动作预览。
- 本地玩家为小满，其余为 AI；外观独立于现有能力和经济规则。
- 城市图鉴、游戏规则、重新开始、浏览器本地自动存档。
- 骰子、逐格脚步、到站、金币收支采用不同的像素风音效；桌面和手机均可开关。
- 音效默认开启，首次交互后解锁播放；静音偏好保存在 `city-dice-sound`。
- 奶油色界面，仅俯视棋盘；电脑端为全窗口棋盘画布，默认完整适应；可放大查看再恢复适应，手机大地图保留局部滚动与行动跟随。
- 起点、奇遇、城市事件 3 种站点及 5 幅原创产业场景；角色按外观配置实时绘制，头像与两帧步行动作共用渲染器。
- 全部 88 座像素地标统一由城市库生成和管理，保留两组绘图风格的原始图像内容。
- 电脑环形路线按可用宽高调整行列，仅重排视觉坐标；格子索引/顺序、产权和人物逻辑位置不变，骰子操作常驻底部。
- 电脑抽卡/抵押/收购使用棋盘中央，长列表内部滚动；玩家资产和测试实际变化使用浮层，不挤压地图。
- 玩家与 AI 统一逐格移动：姓名标识、路径高亮、步数、到站提示及自动滚动到棋盘。
- 人物只显示头像和昵称；棋子站在地块图片上、昵称牌在头顶，不遮挡城市名与价格；资产资料默认收起，道具在中央区域切换查看。
- 棋盘中央常驻当前行动者、位置、现金和城市/产业数量；下方切换动态、公告、自己的道具。
- 动态展示季节加成、有效道具、最近收支和特殊事件；公告保留最近 40 条实际收支/事件，刷新保留，重开清空。
- 道具从中央信息区直接使用；AI 回合仍显示自己的库存，并禁止使用。
- AI（`src/ai.js`，本地规则、不联网）：现金缓冲按下一掷可能付的租金计算；同色组优先买、升、收购，不把成组城市卖给别人；现金充足时不按成本价出售有收益的孤立城市；遥控骰子避开高租/去补组城市，前方有高租城市时开护盾，有可升级城市时开建设补贴；欠款先抵押收益最低且不破坏成组的资产，余钱充足时赎回；事件卡候选、奖励与道具按当前收益及库存价值选择。
- AI 向真人提出收购只在补组、卡组或租金≥报价 30% 时，避免频繁弹窗；任何人使用道具时棋子上方弹出道具牌。
- 回合记录收纳在公告页；原地图外状态条、道具区与回合记录已移除。
- 玩家栏“新增”设置昵称和外观；新角色由 AI 控制，从起点加入。名单、昵称与外观在刷新和重开后保留。
- 名单可横向滚动；同格超过 4 人时显示部分形象和人数，点击选择任意角色查看资产。
- 玩家栏“外观”编辑自己；资产详情“编辑昵称与外观”编辑任意玩家（含 AI），昵称规则同新增角色（≤12 字、不重名），保存后同步所有头像、棋子和公告中的人名。
- 外观写入本地存档，刷新和重开均保留；旧存档自动补全外观，取消编辑不修改配置。
- 点击头像或棋盘人物查看现金、地产净值、总资产、城市等级、租金和抵押状态；同格多人先选昵称。
- 真实收支记录驱动金币飞行、金额滚动与收支提示；资产栏收起时也保留可见反馈。
- 特效层（FxLayer）：买地/收购盖章与彩带、升级光柱与等级、收租金币爆发（≥¥1,000 震屏）、起点横幅、回合横幅、换季粒子与热门区域高亮、破产印章与碎裂、终局烟花与领奖台。
- 特效只读已提交状态、不阻塞操作、不改规则；单次约 1.2～1.5 秒（换季 3.4 秒）；掷骰时棋盘中央大骰子翻滚落地；仅本地玩家参与的大额租金震屏；系统减弱动态时全部关闭。

## 文案约定

界面仅保留状态、规则、金额与操作结果；使用“购买 / 不购买”“升级 / 不升级”等直接表述。
不添加宣传口号或重复的装饰性提示；按用户要求，特殊事件卡保留简短有趣的故事，金额/效果另列，操作文案仍客观。

## 技术方案

- React 19 + Vite 6；当前界面为浏览器 DOM / CSS 实现。
- 游戏引擎使用独立纯 JavaScript 状态转换；随机结果由调用方传入，每次操作返回独立收支记录。
- `src/cityCatalog.js` 是城市资料、素材、价格与分组的唯一数据源；扩展城市配置统一的原型经济参数，原 12 城参数保持。
- `src/board.js` 按城市 ID 生成地图及路径坐标；经典地图保留原索引，旧 v1 存档补为经典地图。
- `src/industries.js` 提供产业目录与纯计价；产权复用 properties，owned 仅城市，ownedAssets 含两类，pendingRent.pricing 保存落点报价。
- 随机地图记录范围、大小和城市 ID 顺序；刷新和普通重开保持同一地图，不重新随机。
- 动画控制器在到站后提交规则结果；动画期间锁定操作，重开会取消未完成动画。
- 随机地图每个色组为 3 / 5 / 7 城；新增城市价格为 ¥1,400～2,600，仅作游戏数值。
- 通用奇遇在 `src/eventCards.js`，逐城定义在 `src/cityEventCards.js`；统一按稳定 ID 查询，城市身份/素材仍只读城市库。
- 城市卡池从实际地图按 cityId 过滤，独立于 eventDeck；抽取、执行和选目标再次校验来源/城市，地图重排不改变入池城市。
- `initialState(roster, map, eventDeck)` 可按事件 ID 配置牌库；去重/过滤未知 ID，空或全无效时回落默认库，重开保留。
- 地图 `cityOrder` 存当前城市排列；只改变顺序，旧经典/随机地图存档仍可读取。
- 新增 rent / offer / debt 待处理阶段，随存档恢复；AI 调度按当前决策人判断，业主确认不要求是其回合。
- 房产记录累计实际升级支出与固定抵押款；旧存档缺失升级支出时按等级 × 标准升级费兼容估算。
- 浏览器本局存档键 `city-dice-v1`，测试键 `city-dice-event-lab-v1`；改名后保留旧键以兼容已有进度；测试不覆盖本局，没有服务端同步。
- 正式素材在 `public/assets/`，SVG 绘制脚本可复现地标和角色。
- CodeGraph 已初始化；索引位于 `.codegraph/`。

## 阶段边界

当前没有微信登录、联机房间、服务端权威状态、排行榜、支付或微信发布包。
尚未部署公网或提交微信审核；微信小游戏与小程序的适配路线仍待确定。
建议先体验并调整规则、节奏、交互，再进入平台适配。
